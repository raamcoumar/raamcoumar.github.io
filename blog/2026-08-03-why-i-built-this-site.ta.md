## ஏன் இந்த தளத்தை உருவாக்கினேன்

பல வருடங்களாக எனக்கு ஒரு தனிப்பட்ட தளம் வேண்டும் என்று ஆசைப்பட்டேன். சிறியது, எளிமையானது, உண்மையில் *எனக்கு* சொந்தமானது — LinkedIn profile அல்ல, Twitter நூல் அல்ல, இணையத்தில் வீடு போல உணரும் ஒரு இடம்.

ஒரு நண்பர் தன் கையால் வரைந்த மினிமலிஸ்ட் தளத்தின் முழு codebase-ஐயும் கொடுத்து, "உன்னுடையதாக மாற்றிக்கொள்" என்றார். நானும் அப்படியே செய்தேன்.

அந்த அசல் தளம் Claude Code-ஆல் கட்டப்பட்டது — தூய HTML, CSS, JavaScript. Framework இல்லை, build step இல்லை, npm install இல்லை. ஒரு folder-லில் இருக்கும் files மட்டுமே. அந்த எளிமைதான் எனக்கு (ஒரு marketer, developer அல்ல) ஒவ்வொரு வரியையும் புரிந்து அதை மறுவடிவமைக்க முடிந்தது.

நான் மாற்றியவை:

- பெயரை மாற்றினேன், நிச்சயமாக
- about பக்கத்தை முழுவதும் மீண்டும் எழுதினேன்
- "works"-ஐ "career" ஆக்கினேன் — அதே mechanic, வேறு கதை
- blog-ஐ முழுவதும் மறுகட்டமைத்தேன்
- ஒவ்வொரு social link மற்றும் contact விவரத்தையும் மாற்றினேன்

வைத்துக்கொண்டவை: கை வரைபடங்கள், color theme அமைப்பு, இருமொழி engine (என் தமிழ் கொஞ்சம் கேள்விக்குறிதான், இருந்தாலும்), இழுத்துச் செல்லக்கூடிய பூனை. சில விஷயங்கள் தொடுவதற்கு மிகவும் நன்றாக இருக்கும்.

நீங்களும் உங்கள் சொந்த தளத்தை கட்ட நினைத்தால்: இதை எடுத்துக்கொள்ளுங்கள். `SWAP-THIS.md` file சரியாக எப்படி என்று சொல்கிறது. அதற்காகத்தான் அது உருவாக்கப்பட்டது.
