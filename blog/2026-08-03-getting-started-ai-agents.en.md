## getting started with ai agents

i've been tinkering with ai agents for a while now — hermes, claude code, building custom workflows. it's wild how far these tools have come in just the last year.

what started as "let me ask chatgpt to write an email" has turned into building full autonomous workflows that can research, write, deploy, and monitor — all while i sleep.

the biggest unlock for me was realizing that you don't need to be a developer to build useful agents. you just need to be clear about what you want and patient enough to iterate.

here are three things i've learned:

1. **start small, then chain.** don't try to build the all-knowing agent on day one. start with one task, get it reliable, then connect it to the next.

2. **the prompt is the product.** a well-written prompt with clear boundaries and examples beats a mediocre prompt wrapped in fancy architecture every time.

3. **agents need guardrails, not freedom.** the best agents are the ones that know when to stop and ask for help. unlimited autonomy sounds cool until it deletes something important.

more to come as i keep building.
